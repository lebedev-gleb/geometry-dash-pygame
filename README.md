# Geometry Dash (PyGame)

2D platformer inspired by Geometry Dash, made with PyGame as a Yandex Lyceum project.

## Features

- Levels are built from text maps (`Map/map.txt`, `Map/map2.txt`), so new levels can be added without code changes
- Tile-based collisions, gravity and jumping
- Side-scrolling camera that follows the player
- Lives, coins, spikes and a finish flag
- Game over screen and level switching

## Controls

| Key | Action |
|---|---|
| A / D | move left / right |
| W | jump |

## Running

```bash
pip install pygame
cd Project_GeometryDash
python main.py
```
